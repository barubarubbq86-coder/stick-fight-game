# 棒人間fight v13｜Phase 5.5＋Phase 6

ビルド不要の3D大軍サンドボックスです。戦場中心の操作画面、大人数の軽量化、旗を守る防衛Challengeを追加しました。自由サンドボックスと巨人の攻撃Challengeを引き続き利用できます。

## 戦場を中心に操作

最初に「自由に遊ぶ」または「チャレンジ」を選びます。Challengeの内容は攻撃／防衛の短いリストから選べます。

戦場の下に「👆選択」「🎥カメラ」「➕配置」「▶戦闘開始」「☰設定」。戦闘中は配置ボタンがSandboxの「⚡神」、開始が一時停止に切り替わります。Challengeの戦闘中に神操作は表示しません。

「設定」は1つのシートで開き、「軍」「戦場」「ルール」「保存・その他」を切り替えます。スマホでは下から約48%の高さ、PCでは右下に表示。設定だけをスクロールでき、「閉じる」で戦場へ戻ります。選択・移動・カメラのボタンは設定を閉じて切り替えます。

- 軍：TEAM、キャラ、軍団、チームプリセット、自作軍団、倍率、クイック編成。
- 戦場：マップ、地形。編成中のSandboxで利用できます。
- ルール：現在のルール、遊び方の変更。
- 保存・その他：配置保存／読込／消去、種類別人数、カメラ、速度など。
- 選択中は戦場の近くに選択数・TEAM選択・Undoなどを表示。タップ・範囲選択、選択集団のドラッグ移動、回転は従来どおりです。
- 2本指はパン・ピンチ。選択操作途中に2本指になった場合、未確定の選択／移動を取り消してカメラへ切り替えます。

## 2つのChallenge

### 攻撃：巨人の守る陣地を突破せよ！

TEAM A、1000コスト。固定されたギガント1体＋槍15体を倒します。既存の内容を維持しています。

### 防衛：3分間、旗を守れ！

TEAM A、1500コスト。中央の青い旗を、戦闘時間180秒まで守ります。旗HPは5000です。自軍は青い中央エリアに配置。敵は0秒・60秒・120秒の3ウェーブで複数方向から襲来します。

- Wave 1：ノーマル36体、3方向。
- Wave 2：剣16体＋ハンマー16体、4方向。
- Wave 3：マッスル4体＋槍16体、4方向。
- 旗HPが0で敗北。兵士が全滅しても旗が生存している間は続行します。
- 敵を早く倒しても、180秒までは防衛を続けます。速度設定は戦闘時間を加速します。
- 旗HP・Wave・残り時間を戦場に表示。結果には旗HP、防衛時間、Wave、撃破数を表示します。

共通：一般近接・一般遠距離・マッスルのみ。敵・地形・倍率は固定、神能力・自由増援・購入・戦闘中資源はありません。単体・大量配置・ブラシ・軍団・チームプリセットに同じ予算制限を適用します。

「同じ編成でもう一度」は自軍・旗HP・敵・Waveを初期化。「編成を変えて再挑戦」は戦闘前の配置を復元。攻撃／防衛／Sandboxで編成と配置保存を独立して保持します。自作チーム・軍団は共有し、適用時に制約を検証します。

## 大人数の軽量化

既存のSpatial GridとInstancingを継続。探索キー・衝突候補判定・経路判定の重複・描画時の配列確保を減らしました。攻撃力、攻撃頻度、移動の物理刻みは維持しています。

700体を超えると描画解像度をCSSピクセル1倍に抑え、影・遠方の多重武器・ヒット演出・飛び道具表示を簡略化。見た目だけのエフェクト数を72に制限し、神能力の主要表示を優先します。攻撃用の飛び道具とダメージ判定は省略しません。UI状態は通常100ms、大人数では200msごとに更新し、操作への応答は即時です。

性能検証は300／600／1000／1500体を実施しています。CPU比較結果と実機未確認の範囲は検証レポートを参照してください。

## 公開と検証

ZIPを展開し、index.htmlが公開先の直下になるようGitHubリポジトリへ配置します。HTTPSの静的ホスティングで動作し、ビルドや外部CDNは不要です。ローカル確認は `python3 -m http.server 8000` でHTTP配信してください。起動エントリーは `game-v13.js`。PWAキャッシュはv13に更新します。

```sh
node --experimental-vm-modules --test --test-concurrency=1 test-results/*.mjs
```

性能計測を他のテストと重ねないため、テストは順番に実行します。DOM・WebGL・Service Workerの確認は模擬アダプターを使用。実ブラウザーの見た目、Android実機FPS、PWA実インストールは未確認です。詳細は `PHASE55-PHASE6-TEST-REPORT.md`。

ステージマップ、報酬、星、アンロック、資源生産、建築購入、オンライン、TPS操作は追加していません。
