# 棒人間fight v8｜Phase 2

## 軍団を置く

1. 「マップを選ぶ」を開き、6種類から選ぶ。配置済み軍団と倍率は維持します。
2. 必要なら「軍団だけ全消去」で空にする。地形・倍率はそのままです。
3. TEAM A〜Dを選ぶ。
4. 「置くもの」をキャラまたは軍団にする。
5. キャラなら1／5／10／25／50／100体を選ぶ。軍団は構成と合計人数を表示します。
6. 陣形と間隔を選び、戦場の地面をタップする。続けて配置できます。

横一列・縦列・四角形・円形・ランダム散開・V字・横長・縦長の8陣形。密集・標準・広めの3段階。大きいキャラの体格に合わせて間隔が広がります。

PCはカーソル、スマホはタッチ中に淡い配置マーカーを表示。岩・壁・既存キャラ・戦場の端を避け、必要に応じて陣形を調整します。全員を置けない場合は追加しません。1タップ分は1回の「元に戻す」で取り消せます。

## マップ

- 大平原：障害物なし。
- 峡谷：2本の長い壁にはさまれた通路と回り道。
- 円形闘技場：円形に並ぶ壁と4つの入口。
- 城壁防衛戦：中央に門のある城壁。
- 丘陵：丘の高低差と岩による進路の分岐。
- 岩だらけの戦場：岩の間を抜ける複数の小さな戦線。

マップ切り替えは地形を置き換えます。軍団が新しい障害物に重なると位置を調整し、人数・種類・TEAM・倍率は維持します。「元に戻す」で地形と位置をまとめて戻せます。手動で地形を変えると「カスタム」表示になります。

## ブラシ

「操作」→「ブラシで配置」を選び、キャラ・1／5／10体ずつ・陣形・間隔を選んでなぞります。1回のなぞり全体を1回の取り消しで戻せます。2本指は移動・ズーム。通常の一括配置モードではドラッグはカメラ操作で、キャラを追加しません。戦闘中の追加配置は従来の1体ずつです。

## 自作軍団

フィールド下の「自作軍団を作る・保存する」で、各キャラの人数と名前を入力します。「選んだTEAMの構成を使う」「選んだ軍団を編集」も利用できます。
現在選んでいる陣形・間隔と一緒に保存します。軍団1つにつき1〜300体、50種類まで。同じ名前は更新します。保存後は軍団メニューから呼び出せます。
自作軍団とフィールド保存は別々です。どちらも同じ端末・同じブラウザー内に保存され、保存領域を消すと失われます。

## 戦闘・保存・再戦

2〜4陣営を配置して「戦闘開始」。倍率・ギガント・戦闘中追加配置・地形編集・全フィールド保存と読み込みは維持。Phase 1の保存データも読み込めます。
「同じ配置でもう一度」は開始時の配置・地形・倍率を復元します。戦闘中の増援は元の編成には加わりません。
