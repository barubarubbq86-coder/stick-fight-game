# 棒人間fight v9｜Phase 3

ビルド不要の3D戦争サンドボックスです。キャラクターの戦闘能力値とPhase 1・2の機能を維持し、チーム全体編成・追従観戦・戦果レポートを追加しました。

## チーム全体を編成

フィールド上の「TEAM全体を編成する」を開き、TEAM A〜Dのカードでプリセットを選んで「このTEAMを編成」を押します。選んだTEAMだけを初期位置へ展開します。既存編成がある場合だけ置換確認が出ます。キャンセルと「元に戻す」に対応しています。地形・他TEAM・陣営倍率を保ちます。

| チーム | 人数 | 配置の特徴 |
|---|---:|---|
| 標準軍 | 52 | ノーマル前衛、左右の剣・マッスル、後方の槍 |
| 近接特化軍 | 48 | マッスル先頭、剣士とハンマーの左右部隊 |
| 遠距離軍 | 38 | 前列の槍系、後方の火・水能力 |
| 大軍 | 300 | ノーマル220・剣40・槍40を4部隊に分ける |
| 少数精鋭軍 | 16 | マッスル・刀・二刀流・火・槍3つ |
| ギガント護衛軍 | 33 | ギガント1、左右の護衛、後方の槍・水 |

強いキャラの元の性能をそのまま使うため、少数精鋭軍の刀などは標準軍より強力です。各軍は同じ強さへ均等化していません。障害物や他部隊がある場合は配置を調整し、全員を置けない場合は置換しません。

「自作チームの配置を保存」で対象TEAMと名前を指定できます。種類・人数・相対配置・向きを保存し、別TEAMでは初期位置と向きを合わせます。保存時の陣形を個々の位置として保持します。1〜1000体、50種類まで。同名は更新です。

## 好きな場所へ部隊を追加

従来の軍団プリセットは配置パレットの「置くもの → 軍団」に残っています。戦場をタップした場所へ一部隊を追加します。チーム全体プリセットとは別です。キャラ1／5／10／25／50／100体、8陣形、3段階の間隔、ブラシ、自作軍団、6種類のマップも維持しています。詳しい従来機能はarchive/README-v8.mdを参照してください。

## 追従観戦

戦闘中にキャラをタップし、「選んだキャラを追従」を押します。カメラ回転・ズームは追従中も使えます。「自由カメラへ」で元の自由視点に戻ります。「全体へ戻る」、移動ドラッグ、2本指移動でも追従を解除できます。対象が倒れた場合は自動解除します。キャラクターを直接操作する機能はありません。

## 戦果・再戦

戦闘終了時に勝者、TEAM別の生存・撃破・実際に削ったHP・投入人数と増援、MVP、最多ダメージ、戦闘時間を表示します。MVPは撃破数、同数ならダメージ、さらに同じなら小さいIDで決定します。撃破されたキャラや消えた死体の戦績も残します。

「同じ条件でもう一度」は開始時のマップ・地形・配置・倍率で再戦します。集計はリセットされます。「編成を変更して再戦」は同じ開始条件を編集画面へ戻します。戦闘中の増援は開始条件へ含めません。乱数を固定する再戦ではないため、同じ編成でも結果は変わり得ます。

## 将来用の内部構造

- data.js：全キャラにcost／roleメタデータを追加。戦闘能力は変更していません。costによる自由モードの配置制限はありません。
- rules.js：GameMode／BattleRules／SandboxMode。勝利判定・コスト・使用可能キャラ・配置可能エリアを差し替える境界を用意しています。timeLimitは設定値で、将来モードの勝利判定側で時間切れの結果を定義します。現在はSandboxのみです。
- battle-stats.js：攻撃・追加配置イベントで集計し、結果を確定する独立した記録層。
- camera-rig.js：自由／追従の切替と追従対象のライブ座標を扱う層。CharacterのAIとカメラ投影から分離し、将来の三人称カメラやPlayerControllerに接続できます。

チャレンジ、防衛、資源、育成、オンライン、外交、直接操作、神の介入は今回追加していません。

## GitHub Pages / PWA

ZIP内のindex.htmlなどをリポジトリ直下にアップロードし、GitHub Pagesを有効にします。サブディレクトリでも相対URLで動作します。新しいteam-presets.js・camera-rig.js・battle-stats.js・rules.jsを含め、全ファイルを一緒に更新してください。ビルドやnpm installは不要です。HTTPまたはHTTPSで起動します。

PWAキャッシュはv9-phase3。初回オンライン読込後はオフライン起動・保存済み軍団とチームの展開に対応します。保存は同じ端末・ブラウザー・公開URL内です。ブラウザーの保存データを消すと失われます。

検証詳細はPHASE3-TEST-REPORT.md、機械出力はtest-results/。Android実機のインストールと実機FPS、GitHub本番公開そのものは未検証です。
