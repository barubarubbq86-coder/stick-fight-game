# 棒人間fight v10｜Phase 3.5＋Phase 4

ビルド不要の3D戦争サンドボックスです。多陣営の混戦を改善し、任意で使える神モードを追加しました。キャラクターの基本能力値と従来の編集・保存機能は維持しています。

## 軍を配備する

「TEAM全体を配備する」を開き、TEAM A〜Dのカードで軍を選び、「この軍を配備」を押します。そのTEAMの軍だけを置き換えます。既に軍がある場合だけ確認が出ます。「元に戻す」で戻せます。他TEAM・地形・倍率は保ちます。

配置パレットの「軍団」は、戦場でタップした場所に一部隊を追加する機能です。TEAM全体の配備とは別です。TEAM → キャラ／軍団 → 人数 → 陣形・間隔 → 地面をタップ、の順で使います。自作チーム、自作軍団、1〜100体の一括配置、ブラシ、6マップを維持しています。

## 多陣営の混戦

3陣営以上が生存している場合、AIが複数陣営の候補を再評価し、近くの脅威・敵への集中度・陣営ごとの狙いの分散を考慮します。一部の部隊は異なる進入地点から中央へ進み、複数の前線が交差します。配置済みの位置は動かしません。

接近した敵には反応して戦い、遠くの敵へ無理にランダム移動しません。2陣営になった場合は従来の探索へ戻ります。二陣営戦の戦闘結果は固定乱数でPhase 3と一致しています。

## 神モード

戦闘中の「神モードに切替」を押し、能力を選んで戦場の地面をタップします。最初はOFFで、AI同士の戦いだけを見ることもできます。

| 能力 | 作用 | クールダウン |
|---|---|---:|
| 神の衝撃 | 半径7、12ダメージ、外側・上方へ吹き飛ばす | 2秒 |
| 神の回復 | 半径8、最大60回復。全TEAMまたは指定TEAM。HP上限まで | 3秒 |
| 神の落雷 | 半径5、90ダメージ、雷の演出 | 4秒 |
| 増援 | 選んだTEAMへキャラまたは軍団を一括投入 | 0.8秒 |

衝撃・落雷は全TEAMへ作用します。「神」キャラの無敵HPは保ち、衝撃の移動効果は受けます。回復で死者は復活しません。増援は従来の追加配置処理を使い、キャラ1〜100体または軍団、陣形・間隔を選べます。置けない場合は追加も回数消費もしません。

神モードでもドラッグ・2本指・ホイールはカメラ操作で、能力を発動しません。「観戦へ戻る」で通常の選択観戦に戻ります。「増援を選ぶ」は神モードの増援へのショートカットです。

クールダウンは実時間で進みます。戦闘を一時停止しても待ち時間は進み、倍速でも短縮されません。決着後は介入できません。再戦ではOFFへ戻り、使用回数と待ち時間をリセットします。

## 観戦・戦果・再戦

キャラをタップ →「選んだキャラを追従」。自由カメラへの復帰や対象死亡時の自動解除も維持しています。

戦果画面は勝者、生存、撃破、実際に削ったHP、MVP、最多ダメージ、戦闘時間を表示します。「神の介入を見る」を開くと衝撃・回復・落雷の回数、増援人数と回数、神による撃破、回復量を確認できます。神による撃破をキャラのMVPに加算しません。

「同じ条件でもう一度」「編成を変更して再戦」は、開始時のマップ・地形・全TEAM・配置・倍率を保ちます。戦闘中の増援や神能力の効果は開始条件に含めません。乱数固定の再戦ではありません。

## 内部設計

- multifront.js：3陣営以上の候補スコア・狙いの集中度・中央への進路。二陣営のAI経路を維持。
- god-abilities.js：神能力の基本値と待ち時間。
- interventions.js：神能力コマンド、待ち時間、回数、集計。空間分割を使う範囲効果。
- rules.js：GameMode／BattleRules／SandboxMode。神能力を禁止・回数制限・待ち時間変更できます。
- battle-stats.js：死亡・死体削除後の戦績も保持し、神による死亡を区別。
- camera-rig.js：観戦追従をCharacterのAIとカメラ投影から分離。

将来のルール設定例（今回はゲーム画面に追加していません）：

```js
new BattleRules({godAbilities:false}); // 全神能力を禁止
new BattleRules({godAbilities:{
  lightning:{maxUses:3,cooldown:6},
  heal:{enabled:false},
  shock:{enabled:false}
}});
```

cost／roleは将来用メタデータ。Sandboxではコスト制限がありません。チャレンジ本体、防衛本体、資源、育成、ステージ進行、オンライン、同盟、キャラ直接操作は未実装です。

## GitHub Pages / PWA

ZIPを展開し、index.htmlなどをリポジトリ直下へアップロードします。npm installやビルドは不要です。GitHub Pagesのリポジトリ名付きURLも相対パスで動作します。全ファイルをまとめて更新してください。

新しいmultifront.js・god-abilities.js・interventions.jsを含む23アセットをv10-phase4のPWAキャッシュへ保存します。初回オンライン読込完了後は、オフラインで編成・神モードも使えます。アップデート後はオンラインで一度再読込してください。

自作軍団・チーム・フィールド保存は同じ端末／ブラウザー／公開URL内です。ブラウザーの保存データを消すと失われます。Android実機のインストール・実機FPS・GitHub本番公開は今回未検証です。
