# 棒人間fight — 3D観戦バトル

外部依存なしのJavaScript / WebGL2 / PWA。既存18種類のHP・攻撃値・特殊確率を維持し、HP300・攻撃50のマッスルを追加。マッスルのパンチ・強パンチ・体当たりはいずれも50ダメージ、範囲と吹き飛び演出を変更します。今回のプレイは観戦のみです。

## 操作
編成人数を設定してFIGHT。1本指ドラッグで回転・上下角度、2本指で移動・ピンチズーム。PCは左ドラッグで回転、右ドラッグかShiftドラッグで移動、ホイールでズーム。「ドラッグ：移動」で1本指の移動も可能。「全体へ戻る」でカメラをリセット。タップで個人HP。

## 構造
- data.js: 能力値・モデル・サイズ・当たり判定半径・AI種別・予備動作を定義。
- simulation.js / Character: 位置(X,Y,Z)・向き・移動・攻撃モーション・ダメージ・吹き飛び。commandを消費する側。
- AIController: ターゲットと移動・攻撃指令を生成する側。Character.setController()で将来のPlayerControllerへ交換可能。今回プレイヤー操作UIは未実装。
- Battle: 空間分割、飛翔体、範囲攻撃、分離、HPと勝敗。30Hz固定更新。3戦域の配置から開始し、X/Z方向に回り込みます。
- Terrain: heightAt / canOccupyは将来の高低差・障害物の差し込み口。現段階は平地。
- render3d.js / Renderer3D: 低ポリゴン立体モデルを2種類のメッシュへまとめてインスタンシング。registerModel(name,builder)で別体型を追加でき、戦闘本体はモデル形状に依存しません。
- SpectatorCamera: 透視投影、回転、角度、パン、ズーム。描画側はcamera.update / matrix / eye / projectインターフェースで利用するため、将来のFollowCamera等へ交換可能。

槍・炎・水・ダンベルは飛翔時間後にダメージ判定。移動して着弾地点から離れた敵は避けられます。刀・全槍・神の刀と雷は全生存敵への攻撃を維持。神同士のみ残ったらDRAW。水は1.3秒転倒。死体は2秒後に回収。攻撃前動作とクールタイムを加え、HPや攻撃力を下げずに観戦しやすくしています。

## 性能
4単位セルの空間分割。敵検索は近隣セルを先に調べ、セル内の候補を分散。AI更新は約0.25〜0.4秒間隔。分離は近隣候補だけ。エフェクト180件・描画飛翔体180件の上限は描画のみで、ダメージ判定は省略しません。エフェクト・弾・セル配列は再利用。画面外カリング、遠方モデルの簡略化、人数に応じた描画解像度低下。人数の固定上限は設けていませんが実際の上限は端末性能によります。

## GitHub Pages
公開用はdist内のファイルだけをGitHubリポジトリ直下へアップロード。Settings → Pages → main / root。HTTPSで開いたあとChromeからホーム画面に追加。配信と初回のキャッシュ取得以外の通信はありません。広告・課金・情報収集なし。WebGL2対応ブラウザが必要。

## 戦闘中の追加配置
「キャラを追加配置」を押し、TEAM A（青）/ TEAM B（赤）と種類を選択。戦場の地面をタップすると、その場所へ1体追加します。同じキャラを続けて配置できます。「配置終了」で通常操作へ戻ります。配置モードでも明確なドラッグや2本指の操作はカメラ操作になり、配置しません。戦場外や画面のボタン上には配置しません。一時停止中も配置でき、再開後に行動します。追加キャラは約0.35秒待ってAIへ参加します。勝敗確定後は配置できません。

HPバーの分母は「初期HP合計＋これまで追加したキャラの最大HP合計」です。追加時に現在HPと最大HPの両方が増えます。再戦時は最初の編成へ戻り、途中で追加したキャラは引き継ぎません。

## Androidへのインストール
GitHub PagesのHTTPS公開URLをChromeで開き、表示された「インストール」ボタン、またはChromeのメニューの「ホーム画面に追加」「アプリをインストール」を使います。表示名はChromeのバージョンによって異なります。インストール後はアプリのように単独画面で起動します。最初にオンラインで読み込みとキャッシュ作成を済ませてください。ゲーム本体はその後オフラインでも起動できます。

## 完成ZIPの公開
ZIPを展開し、**中のファイルをすべて**リポジトリ直下へアップロードしてください。index.htmlが直下にある状態にします。Settings → Pages → Deploy from a branch → main / (root) → Save。公開URLを開けば遊べます。リポジトリ名を含むサブパスにも対応しています。

## 更新とキャッシュ
sw.jsのCACHEのバージョンを更新すると、必要ファイルをまとめて新しいキャッシュへ保存し、同じリポジトリの旧キャッシュを削除します。異なるサブパスのキャッシュは削除しません。更新後はゲームを閉じて再読み込みしてください。キャッシュ済みファイルは同じバージョンから読み込むため、オフライン時に新旧モジュールが混ざりません。

## 最終検証
50対50・100対100・300対300に追加配置し、AI参加・ID重複なし・HP集計を検証。ブラウザで連続10体配置、チーム/種類切り替え、ドラッグ/ピンチの誤配置防止、戦場外の拒否、勝敗後の配置禁止、再戦、縦横画面の表示を確認。/repo/というサブパスでPWAのmanifestとインストール条件を確認し、ネットワークを切って再読み込み・戦闘開始を確認しています。Android実機でのインストール操作と実機性能は未確認です。
