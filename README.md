# 棒人間fight v12｜Phase 5

ビルド不要の3D戦争ゲームです。Phase 4.5の自由サンドボックスを保ち、コスト制Challengeを1ステージ追加しました。

## 遊び方

最初に「自由に遊ぶ」または「チャレンジ」を選びます。「遊び方を変更」で切り替えられ、両モードの編成は別々に保持します。

自由に遊ぶ：TEAM A〜D、無制限の編成、マップ、倍率、チート級、ギガント、神の衝撃・回復・落雷・増援を従来どおり利用できます。

チャレンジ：「巨人の守る陣地を突破せよ！」。TEAM Aを1000コスト以内で編成し、ギガント1体＋槍15体の固定敵軍を倒します。青いエリアに自軍を配置してください。画面上部に使用コストと残量が表示されます。

- キャラ・軍団・大量配置・ブラシ・チームプリセットを使用できます。コスト超過の操作は実行されません。
- 一般近接・一般遠距離・マッスルを使用できます。全槍・刀・神・ギガントは使用不可です。
- 敵・地形・倍率は固定。神能力と戦闘中増援はありません。
- 兵士のタップ／範囲選択、集団ドラッグ移動、回転、Undoを利用できます。配置エリア外への移動は確定しません。2本指はカメラです。
- 結果に敵残存数、ギガント残りHP、自軍撃破数を表示します。
- 「同じ編成でもう一度」は全員のHPと位置を初期化。「編成を変えて再挑戦」は戦闘前のTEAM A配置を復元します。
- 通常のチームプリセットには必要コストと使用不可表示が付きます。Challenge向けの3編成も同じプリセット機構から利用できます。
- 全体配置の保存先はモード別です。チーム・軍団の自作プリセットは共有し、使用時にルールを検証します。

## 公開

ZIPを展開し、index.htmlが公開先の直下になるようGitHubリポジトリへ配置してください。GitHub PagesなどHTTPSの静的ホスティングで動きます。ビルドや外部CDNは不要です。ローカル確認はプロジェクト内で `python3 -m http.server 8000` を実行し、`http://localhost:8000/` を開きます。file://で直接開くとES Modules／PWAを使用できません。

起動エントリーは `game-v12.js` です。PWAキャッシュはv12で更新し、同じ公開サブパスの旧キャッシュだけを削除します。

## 構造

既存のGameMode／BattleRules／Character.cost／FieldEditor／Battleを拡張しました。`challenges.js` がステージ定義、`challenge-mode.js` が配置検証・固定敵検証・勝敗条件です。基本能力・既存cost・AI・多陣営戦闘の調整はしていません。複数ステージ、報酬、成長、資源、防衛戦などは未実装です。
